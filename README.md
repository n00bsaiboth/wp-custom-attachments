# WP Custom attachments

Simple plugin to add an attachments outside document root, so it's not accessible via browser or search engines. Inspired a little bit by ACF.

## How to use

Create an article or post and use the shortcodes. 

### List attachment files

If a current article or post has attachements, list files with the following command:

```[wca_file_list]```

### Add a form to upload files

```[wca_upload_form]```
